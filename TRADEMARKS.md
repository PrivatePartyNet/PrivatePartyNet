# The PrivatePartyNet name and icon

"PrivatePartyNet" and the PrivatePartyNet icon (a monitor wearing a party hat, with confetti on the screen) identify this
project.

The source code is licensed under the Apache License, Version 2.0, and that license covers the code. Section 6 of the license
does not give permission to use the project's name, marks or product names, except to describe where the work came from.

In practice:

- You may fork the code, change it, build it and share it under the license.
- A fork or a changed build should have its own name and icon, so that nobody mistakes it for the original.
- You may use the name to describe things truthfully: "works with PrivatePartyNet", "based on PrivatePartyNet", "a fork of PrivatePartyNet".
- Please do not use the name or icon in a way that suggests the project made, approved or supports your product.

The name has not been registered as a trademark. This page states how the project asks its name to be used. It is not
legal advice.
