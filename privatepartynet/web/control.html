Your party

  
Your party is open. PCs on this network see you under Nearby PCs and can ask to join. You let each one in.

  

  

    
  

  
Server password: . People on your network do not need it; people joining from outside do, and invites carry it.

  

    Change the password
    
Everyone you let in before still comes back by who they are. New people need the new password, so copy a new invite afterwards.

    
    

  

  

  

    Relay server
    
For members whose routers let nothing through, on both sides. Your group runs it on a small rented server (relay/README.md says how). What passes through it is encrypted and it cannot read it. The secret stays on this PC: members get short-lived credentials from it, signed by this PC.

    

    
    
    
    

      
      
    

  

  

    
    
  






  
Join a party from anywhere

  
Paste an invite code from the host. They see your request and let you in.

  
  

    
    
  

  

    Join with an address and a password
    
An invite code also checks that you reach the right host. With only an address, the first certificate seen is trusted and remembered.

    Game network
    
  
    Each server is also a private network for games that play over a LAN. Pick the one to play on: this PC gets that server's game address, shown with a green light, and games see it as an ordinary network card. Windows asks for permission once each time it is turned on.
    
  
      
  
      Start your party or join one to use its game network.
      
  
      
  
      
  
      
  
      
  
  
  
      
  
  
      
    What party members can reach on this PC
    
      Games always work. Windows' own services are closed to party members unless you open them here. This is for this PC only and takes effect at once. Bonjour (mDNS), which some games use to find each other, always stays open.
      
    
      
  
      

      


      
  
      Direct messages
      
  
      Write to anyone on your network, with no party open. Messages are sealed to the other person's key and kept on both PCs.
      
  
       
      

      


      
  
      Saved chats
      
  
      Your chats are kept on this PC, encrypted, in your own PrivatePartyNet folder.
      
  
      
    
    
      
  
      
  
      
    Add a password
    
      Windows already protects the key for your sign-in. A password adds a second lock. If you forget it your saved chats cannot be recovered; a backup file with its own passphrase is the safety net.
      
    
    
    
      
  
      
  
      
    Back up or move your chats
    
      One compressed file with every chat and picture, sealed with a passphrase you choose. Importing adds what is missing and never changes what is here.
