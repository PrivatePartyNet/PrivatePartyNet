# Research and planning

Planning documents and the research behind them, one folder per month (`YYYY-MM`), named for the month they were written.
They are proposals and findings, not documentation of the app as it is: the app's own docs are the README, SECURITY.md and
the How page. Each month's folder has a README listing what is in it and whether each plan is settled.

Each research file says who ran it, when, the question, where it is used, and where every finding came from ("search
summary" for a search tool's summary, "fetched" for a page read in full). Check a claim against its source before building
on it.
